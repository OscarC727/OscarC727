## What I'm working on

- **IEEE EXO.** I lead the controls side of a student-built exoskeleton that assists hip and knee movement, using four AK80-9 motors, a Jetson Orin Nano, and Teensy sensor boards on a CAN bus. Right now I'm working on gait-phase detection with force sensors and a state machine, while logging IMU data to improve it later.
- **[In the Balance](https://github.com/OscarC727/rotary-inverted-pendulum).** A rotary inverted pendulum the controls team is building as practice before the exo. I run PID workshops for the team alongside it.
- **[N-bit ALU in Verilog](https://github.com/OscarC727/fpga-verilog).** A parameterized ALU with testbenches that check over 1.5 million cases. Next up is sequential logic on the Tang Nano 20K.
